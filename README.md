# Rotundák, pálosok, Szent Kereszt

Interaktív térkép a történeti Magyarország rotundáiról, pálos helyeiről és Szent Kereszt nevű helyeiről.

- Szín: piros = kerektemplom (rotunda), sötétkék = pálos hely, világoskék = pálos kapcsolódású barlang, sárga = Szent Kereszt nevű hely
- Alak: négyzet = ma is áll, kör = a romja megvan, szaggatott kör = csak a (feltételezett) helye ismert
- Méret: nagy jel = pontos koordináta (±100 m-en belül), kis jel = pontatlan

Adatforrás: Rotundak_tortenelmi_Magyarorszag.xlsx, 2026-10-18.
Alaptérképek: Esri, OpenStreetMap közreműködők, Natural Earth.
